# Редакции SMENORA

SMENORA использует **одну кодовую базу**. Редакции не должны иметь отдельных веток исходного кода или дублированных файлов приложения.

Редакция определяется набором разрешённых возможностей (`features/entitlements`) и лимитов.

## Start

Предназначена для базового знакомства и небольших рабочих контуров.

Предварительно включает:

- сотрудников и специальности;
- базовые смены и ручной график;
- базовый учёт отсутствий;
- базовый импорт/экспорт;
- резервное копирование пользовательских данных.

Предварительный лимит активных сотрудников: **15**.

## Standard

Основная рабочая редакция учреждения.

Предварительно включает возможности Start и дополнительно:

- табель;
- план-график и план/факт;
- контроль покрытия;
- подбор и оформление замен;
- автоматическое формирование графика базового уровня;
- расширенные отчёты.

Предварительный лимит активных сотрудников: **100**.

## Professional

Расширенная редакция для сложного сменного планирования.

Предварительно включает возможности Standard и дополнительно:

- продвинутый оптимизатор;
- балансировку нагрузки;
- расширенную аналитику;
- кадровые риски и устойчивость;
- сценарное планирование.

Предварительный лимит активных сотрудников: **300**.

## Важно

Конкретный коммерческий состав редакций, цены и лимиты могут быть скорректированы до публичного коммерческого релиза.

В коде не должно быть распределённых проверок вида `if edition == "PRO"`. Используется единая модель возможностей, например:

```python
features.has("schedule.optimizer")
features.has("analytics.advanced")
```

Подключаемые коммерческие модули лицензируются отдельно от редакций и описаны в [MODULES.md](MODULES.md).
