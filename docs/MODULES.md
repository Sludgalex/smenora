# Подключаемые модули SMENORA

Подключаемые модули развиваются независимо от редакций Start / Standard / Professional и должны использовать стабильный Core API.

## Attendance

Модуль учёта фактического присутствия сотрудников.

Целевая функциональность:

- PIN-регистрация;
- QR-регистрация;
- точки регистрации;
- приход/уход;
- фактическое время;
- удалённые точки;
- журнал регистрации;
- отчётность.

Модуль находится в активном процессе архитектурного отделения от монолита. Legacy API сохраняется через compatibility wrappers до завершения миграции.

## Compensation — «Оплата труда»

Единый коммерческий модуль, объединяющий ранее раздельно рассматривавшиеся Salary и KPI.

Целевая функциональность:

- предварительный расчёт оплаты труда;
- оклады и ставки;
- ночные, праздничные и сверхурочные часы;
- доплаты и стимулирующие выплаты;
- KPI;
- эффективный контракт;
- коэффициенты и балльные показатели;
- расчётные листы и отчёты.

Внутри архитектуры могут существовать отдельные feature keys, например:

```text
compensation.salary
compensation.kpi
compensation.incentives
compensation.effective_contract
compensation.reports
```

но для коммерческого пользователя это один модуль **«Оплата труда»**.

## AI

Направление зарезервировано архитектурно, но пока не относится к готовому коммерческому функционалу.

В будущем AI может использоваться для объяснения графиков, анализа проблем, подготовки документов и команд естественным языком. Детерминированные расчёты графиков, норм и ограничений должны оставаться в Core/solver, а не передаваться языковой модели.

## Принципы модульности

- Core не импортирует бизнес-логику модуля;
- модуль использует только документированные Core API/services;
- модули не должны напрямую импортировать реализацию друг друга;
- каждый модуль имеет manifest и собственную версию;
- совместимость проверяется по Core API, а не по номеру релиза SMENORA;
- отключение модуля не должно удалять его данные;
- модульные routes используют отдельный namespace;
- неизвестный пользовательский Python-код автоматически не загружается.
